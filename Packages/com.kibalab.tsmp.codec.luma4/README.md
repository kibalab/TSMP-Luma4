# TSMP Codec Luma4

Default TSMP codec package. Luma4 is the recommended baseline codec for first setup and stream-path diagnostics.

## Requirements

- TSMP Core: https://github.com/kibalab/TSMP-Core
- `com.kibalab.tsmp.core` 0.0.1 or newer
- VRChat Worlds SDK 3.9.0 or newer

## Usage

Install this package with TSMP Core, add the Core `Samples/TSMPController.prefab` to your scene, then select `Luma4` in the `TSMPSetup` Codec tab and run `Apply Setup`.

## Release Status

This package is currently beta and uses `v0.0.x-beta.x` tags.
