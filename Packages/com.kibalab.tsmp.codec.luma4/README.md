# TSMP Codec Luma4

Luma4 TSMP codec, Udon handler, shaders, materials, and prefab.

## Requirements

- `com.kibalab.tsmp.core` 0.0.1 or newer
- VRChat Worlds SDK 3.9.0 or newer

## Usage

Import this package with TSMP Core. `TSMPSetup` discovers `Runtime/TSMPCodecCatalog.asset` in the editor and adds the Luma4 codec prefab to the codec list automatically.

Luma4 is the default low-bandwidth codec and is suitable as the baseline codec dependency for TSMP worlds.
